Proyek Akhir: Aplikasi Rekening Bank Interaktif

Gabungkan konsep Method Non-Void, Enkapsulasi Data Private, dan Exception Handling Try-Catch dalam satu aplikasi lengkap.

Status Proyek: Belum Diverifikasi

Syarat & Kriteria Aplikasi

1. Method Non-Void

Memiliki method non-static `hitungSetoran()`, `tarikSisa()`, atau `getInformasi()`. Wajib kata kunci `return`.

2. Enkapsulasi Private

Variabel `private double saldo;` dan `private String pin;` diakses via Getter & Setter tervalidasi.

3. Error Handling

Program dibungkus blok `try-catch` untuk menangkap input non-angka atau penarikan melebihi saldo.
