                    Modul 2 • Pemrograman Java XI RPL
                    
Enkapsulasi & Access Modifier Private

                    
Proteksi data variabel dengan `private` serta pengaksesan aman melalui `Getter` dan `Setter` tervalidasi.

                


                
                

                    
                    

                        

                            

                                 Apa itu Enkapsulasi?
                            

                            

                                **Enkapsulasi (Encapsulation)** adalah teknik membungkus atribut variabel agar tidak dapat diubah secara bebas oleh pihak luar. Caranya adalah memberi akses **`private`** pada variabel, lalu menyediakan method **`public Getter`** (membaca) dan **`Setter`** (mengubah dengan validasi).
                            

                            

                                Aturan Utama:
                                
    
                                    
  • private double saldo; (Akses langsung dari luar class DITOLAK)
    • 
                                    
  • public double getSaldo() (Membaca nilai saldo)
    • 
                                    
  • public void setSaldo(double s) (Mengubah saldo dengan syarat > 0)
    • 
                                

                            

                        


                        
                        

                            

                                RekeningBank.java
                            

                            
public class RekeningBank {
    // Atribut disembunyikan (Private)
    private double saldo = 500000;

    // Getter: Membaca nilai saldo
    public double getSaldo() {
        return this.saldo;
    }

    // Setter: Mengisi saldo dengan Validasi
    public void setSaldo(double saldoBaru) {
        if (saldoBaru >= 0) {
            this.saldo = saldoBaru;
        } else {
            System.out.println("Error: Saldo tidak boleh negatif!");
        }
    }
}

                    Modul 3 • Pemrograman Java XI RPL
                    
Error Handling (Try, Catch & Finally)

                    
Mengamankan aplikasi agar tidak crash tiba-tiba saat terjadi Runtime Exception.

                


                
                

                    
                    

                        

                            

                                 Blok Pertahanan Try-Catch-Finally
                            

                            

                                Saat program mengalami kesalahan runtime (seperti pembagian nol atau input teks pada angka), program Java akan **crash**. Blok **`try-catch`** mencegah hal tersebut!
                            

                            

                                

                                    try { ... } : Berisi kode yang berisiko memicu error.
                                

                                

                                    catch (Exception e) { ... } : Menangkap & menangani error jika terjadi.
                                

                                

                                    finally { ... } : Selalu dieksekusi di akhir (ada error maupun tidak).
