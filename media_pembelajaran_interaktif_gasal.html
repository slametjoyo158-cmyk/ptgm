Modul Pembelajaran 1

Method Non-Void Non-Static (Instance Method)

Mempelajari deklarasi, pembuatan objek (`new`), nilai kembalian (`return`), serta perbandingan tanpa & dengan parameter.

Konsep Dasar Method Non-Void Non-Static

Ciri Utama Method Non-Void Non-Static:

  • Tanpa keyword `static`: Harus dipanggil melalui objek hasil instansiasi (`new`).
  • Bukan `void`: Memiliki tipe data kembalian (contoh: `int`, `double`, `String`, `boolean`).
  • Wajib kata kunci `return`: Mengembalikan satu nilai data sesuai tipe deklarasi.

Perbedaan Parameter:

  • Tanpa Parameter: `hitungPI()` — Tidak menerima input saat dipanggil. Mengolah variabel internal/lokal.
  • Dengan Parameter: `hitungLuas(int p, int l)` — Menerima data masukan dari pemanggil untuk diolah.

Modul Pembelajaran 2

Enkapsulasi (Encapsulation) & Private Modifier

Memahami penyembunyian data (*Data Hiding*) menggunakan modifier `private` dan pemanfaatan `Getter` & `Setter` dengan validasi.

1. Private Modifier

Variabel bertipe `private` hanya bisa diakses langsung di dalam kelas yang sama. Mencegah manipulasi ilegal dari luar.

2. Getter Method

Method *non-void* yang bertugas mengembalikan (*read-only*) nilai variabel `private` ke dunia luar.

3. Setter Method

Method *void* atau *non-void* yang diberi nilai masukan (*write*) untuk mengubah nilai `private` disertai filter validasi data.

Simulator Perisai Akses Objek Rekening Bank

public class RekeningBank { // Data sensitif dilindungi dengan private private double saldo = 500000.0; // GETTER: Membaca Saldo public double getSaldo() { return this.saldo; } // SETTER: Mengubah Saldo dengan Validasi public boolean setSaldo(double nominal) { if (nominal < 0) { return false; // Ditolak! } this.saldo = nominal; return true; } }

Modul Pembelajaran 3

Error Handling (Try, Catch & Finally)

Penanganan exception secara elegan agar program tidak crash ketika menghadapi masalah saat *runtime*.

1. try { ... }

Blok kode yang berpotensi mengalami error (misal: pembagian dengan nol, akses index array diluar batas, query database).

2. catch (Exception e)

Blok yang hanya dieksekusi jika terjadi error di dalam blok `try`. Berfungsi menangkap error dan memberikan solusi/pesan.

3. finally { ... }

Blok yang SELALU dijalankan, baik terjadi error maupun tidak. Biasa dipakai untuk menutup koneksi atau membersihkan RAM.
